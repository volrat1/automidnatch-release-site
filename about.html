ABOUT THIS PROJECT

A compact production experiment using Renoise project data as a structured surface for developing human-authored musical material.

01 / SUMMARY

Summary

This release was developed through Automidnatch Production Systems (APS), an experimental workflow for extending, arranging and refining musical material created in Renoise.

02 / CONTEXT

Context

Renoise stores projects in a structured format and exposes additional control through Lua. APS explores how those properties can support a transparent, editable and musician-led human–AI production workflow.

03 / OBJECTIVES

Objectives

  • Develop short musical cells into complete tracks.
  • Preserve creative authorship and manual selection.
  • Use structured project data instead of opaque audio generation.
  • Explore workflows that could be useful to the Renoise community.

06 / CONCLUSIONS

Conclusions

APS suggests a model in which AI operates on inspectable musical structures while the musician retains authorship, evaluation, editing and final control.

07 / FUTURE WORK

Potential directions for Renoise

  • XRNS-aware project analysis and transformation.
  • Lua tools for controlled variation, modulation and arrangement.
  • Readable diffs between project states.
  • Reusable workflows for human–AI collaboration inside tracker-based production.
